# screen-protector

Case that closes over a ~7 in screen + its cables; make it structurally sound and bolt-together

Parts are defined in `screen_protector.py`; source STLs to edit go in `source/`.
Build: `python build.py screen-protector` (repo root) -> `out/screen-protector/stl/`.
Context, dimensions and rules: `CLAUDE.md`. History: `docs/DESIGN_LOG.md`.
