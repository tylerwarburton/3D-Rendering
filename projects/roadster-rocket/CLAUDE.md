# Roadster vs. Rocket

## Goal

Create a fictional 10-second cinematic in which a bright-red, Roadster-inspired
electric sports car gets a one-second head start before a stainless launch
vehicle ignites, the car is engulfed by smoke, and it escapes into a final hero
composition beneath the rising rocket.

This is an original speculative concept. It must never be presented as footage
of a real Tesla, SpaceX, or other launch event.

## Fixed production specifications

| Item | Value |
|---|---|
| Timeline | 300 frames |
| Frame rate | 30 fps |
| Master resolution | 1920 x 1080 |
| Car starts moving | Frame 45 |
| Rocket ignition | Frame 75, exactly 1.0 s after car motion starts |
| Rocket liftoff begins | Frame 165 |
| Closing title begins | Frame 270 |
| Car dimensions | 4.5 x 1.9 x 1.2 m |
| Rocket height | 83.5 m |
| Track axis | +X; Z is up |

## Project rules

- Use Blender 4.3+ with Eevee; the scene must be genuinely 3D.
- All geometry is original procedural geometry. Do not use Tesla or SpaceX
  trademarks, logos, or downloaded models.
- Keep vehicle and rocket geometry consistent for all shots.
- Animation state is derived from the current frame; no arbitrary per-frame
  teleportation.
- The disclosure must be legible in the closing shot and a smaller
  `SPECULATIVE CONCEPT` bug remains visible throughout.
- Rendered deliverables go in the repository-level `output/` directory.
