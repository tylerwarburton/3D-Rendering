# flag-badge

Remove a side logo from an STL and add a raised, paintable US flag (test plate first)

Parts are defined in `flag_badge.py`; source STLs to edit go in `source/`.
Build: `python build.py flag-badge` (repo root) -> `out/flag-badge/stl/`.
Context, dimensions and rules: `CLAUDE.md`. History: `docs/DESIGN_LOG.md`.
